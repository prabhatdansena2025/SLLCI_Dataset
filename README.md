"# SLLCI_Dataset" 

The repository contains the dataset for the synthetic low-light cheque images.
Anyone using this dataset must cite as follows: 

Prabhat Dansena, Ashish Ranjan, Soumen Bag and Prasun Chandra Tripathi, "A Zero-Reference Approach Employing γ-Correction + Dilated-ZeroDCE++ for Handwritten Cheque Image Enhancement", ICPRAM 2026.

P. Dansena, S. Bag, and R. Pal, “Differentiating Pen Inks in Hand-written Bank Cheques Using Multi-Layer Perceptron”, Proc. of 7th International Conference on Pattern recognition and Machine Intelligence, Kolkata, India, December 2017. (As well-lit images has been taken from IDRBT Cheque Image Dataset (https://www.idrbt.ac.in/idrbt-cheque-image-dataset/).
